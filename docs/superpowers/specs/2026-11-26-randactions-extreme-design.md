# #16 Randactions: Extreme 難易度の設計

対象: `examples/16/`（core.js・main.js・index.html・worker.js）
状態: 会話で合意済みの内容をまとめたもの。「（判断）」と付けた項目は Claude の判断で、ユーザーが未確認。

## 1. 目的

Easy / Hard の上に Extreme を足す。Easy / Hard は現状のまま残す。

Hard が難しくならない原因は keep にある。keep は経路の足場の上 3 段、跳ぶ区間の上空 4 段、足場の間を長方形で確保していて、どんな軌道でも通れる。そのため、軌道を絞る（テクニックを要求する）配置を置けない。Extreme では、菱型の天井や壁で動ける範囲を狭めた「区間」を経路に組み込み、決まった操作を要求する。

## 2. 目標・非目標・アンチゴール

- 目標
  - 1 ステージに「難配置」を最低 3 か所、最大 5 か所入れる。どれも練習すれば越えられる難しさ（会話の A 案）にする。
  - 緩急を付ける。「癒し区間」（少し易しく、「ここはできる」と感じられる区間）を 1〜2 か所入れる。
  - 難配置は飛ばせない（抜け道がない）ことを生成時に確かめる。
  - 同じ種類の区間を続けず、飽きにくくする。
- 非目標
  - Easy / Hard の生成結果を変えること。同じシードなら同じステージが出ること。
  - 物理・操作・ステージの大きさ（25×22）・描画を変えること。
  - 0.05〜0.1 秒級の精密操作（会話の B 案）。
- アンチゴール（形のうえで動いても失敗とみなすもの）
  - 難配置を迂回できるステージが普通に出る。
  - 見ても何を要求されているか分からない配置（ばらまいた菱型による理不尽さ）。
  - Easy / Hard の用意が Extreme の生成待ちで遅れる。

## 4. 用語

- **区間**: 型（テンプレート）から置く、経路の一部。種類と、難配置 / 癒し区間の段階を持つ。
- **入口の足場 / 出口の足場**: 区間に含まれる最初と最後の足場。直前の普通の足場から、普通のジャンプ 1 回で入口の足場に乗る。次の普通の足場へは出口の足場から跳ぶ。
- **着地場所**: 入口の足場のうち、上が空いている部分。ここに着地してから区間に挑む。
- **本体**: 区間の中で、意図した軌道が必ず通るマス。抜け道の判定に使う。
- **抜け道**: 難配置の本体に一度も触れずにゴールへ届く道。

## 5. 幅の物差しと段階

**幅**は次のように測る。区間を空のステージに単独で置き、着地場所（`S`）から右（左向きの区間は左）を押し続ける。押す時期・離す時期・2 回目の押下・切り返しの時期をそれぞれ独立に ±r tick ずらしても、必ずクリアできる最大の r を求め、幅 = 2r+1（tick、1 tick = 1/60 秒）とする。

この測り方は人間に対しては厳しめに出る（人間は空中で止まるなどの工夫ができる）。そのため秒数の絶対値ではなく、ユーザーが実際に試した地形（落下→空中ジャンプ、ネズミ返し）と比べた段階で扱う。

| 段階 | 幅（tick） | 役割 |
|---|---|---|
| 普通 | 15 | 菱型のない穴越え（参考） |
| 癒し区間 | 9〜11 | 「ここはできる」と感じる区間 |
| 難配置 | 3〜5 | ユーザーの例と同じ段（A 案） |
| 使わない | 1 以下 | 厳しすぎる（B 案の側） |

## 6. 区間の型

右向き（左から入って右へ抜ける）で定義し、左向きは左右を反転して使う。ネズミ返しだけは折り返し専用で、入った向きと逆に抜ける。

記号: `E` 入口の足場、`X` 出口の足場、`=` ほかの四角、`#` 菱型、`o` 本体（空き）、`.` 予約（空き）、`S` 着地場所（空き、テストの開始位置）、`G` テストのゴール位置（空き）、`-` 区間の外（何を置いてもよい）。

以下はすべて実測済みで、表の値は 5 章の物差しで測った幅。左右反転版でもクリアできること、難配置は本体を菱型で埋めるとクリアできなくなる（単独では抜け道がない）ことを確かめてある。図は実装した最終の形（hop・overhang・roomy は実装時に予約の行を足した。14 章）。

本体（`o`）の周り 8 マスは、必ず型の中（`-` 以外）に入れる。型の中は keep になるので、飾りの菱型が本体のすぐ横に来て、測った幅より難しくなることを防げる（判断）。

### 難配置

**drop（落下→空中ジャンプ）** 幅 3。ユーザーの例に、着地場所と、天井を越える抜け道を塞ぐ縦 2 マスの菱型を足した形。縦の菱型が無いと、着地場所から 2 段ジャンプで天井を越えられた。
```
---#------
--.#####.-
S..ooooo..
EEEEoooo.G
---=oooXXX
---=...#--
```

**hop（低い天井の小ジャンプ）** 隙間 g = 2 / 3 / 4、幅 3 / 3 / 5。
```
---.####.-      （図は g=2。天井は g+2 マス）
....oooo..
S...oooo.G
EEEEooXXXX
---....---
```
行の作り方: `'---.' + '#'×(g+2) + '.-'`、`'....' + 'o'×(g+2) + '..'`、`'S...' + 'o'×(g+2) + '.G'`、`'EEEE' + 'o'×g + 'XXXX'`、`'---.' + '.'×g + '.---'`。足場から歩いて少し落ちてから跳ぶと隙間の行に入るので、隙間も本体にし、その下の行も空けておく。

**capped（天井付きの 2 段ジャンプ）** 穴 g = 1 / 2 / 3、幅はどれも 3。3 段上の足場の上を、頭上に 1 段空けて菱型の天井で塞ぐ。天井は区間の上全体に張る。上段の足場は天井の外へ 2 マス延ばし、次のジャンプの踏み切りにする。手前は穴にする（壁だと張り付いて跳べてしまう）。
```
#########--     （図は g=2。天井は g+7 マス）
....oo.....
....oo.G...
....ooXXXXX
....oo.....
S...oo.....
EEEE.......
```
行の作り方: `'#'×(g+7) + '--'`、`'....' + 'o'×g + '.....'`、`'....' + 'o'×g + '.G...'`、`'....' + 'o'×g + 'XXXXX'`、`'....' + 'o'×g + '.....'`、`'S...' + 'o'×g + '.....'`、`'EEEE' + '.'×(g+5)`。

**overhang（ネズミ返し）** 幅 3。ユーザーの地形に、左 2 列の着地場所を足した形。反対側（左）は菱型 2 段と四角で塞いである。上の `X` が出口の足場で、そこから逆向き（左）へ進む。`G` はテスト用で、ネズミ返しの上に置く。
```
-.....--
..X.....
..#Gooo.
..#==o..
...ooo..
S..ooo..
EEEE....
```
1 行目は、ネズミ返しの上から X へ跳ぶときに通るので空けておく。

### 癒し区間

**gate（広めの菱型ゲート）** 開口 3 段・穴 3、開口 3 段・穴 4、開口 4 段・穴 4。幅はどれも 9。ゲートの列は穴の中央の 2 列（穴 3 なら左から 4・5 列目、穴 4 なら 5・6 列目）。
```
----##----      （開口 3・穴 4）
..........
..........
..........
S...##..G.
EEE....XXX
```

**roomy（天井まで 2 段空けた小ジャンプ）** 隙間 g = 3 / 4、幅 9 / 11。hop の天井を 1 段上げた形。
```
----#####--     （図は g=3。天井は g+2 マス）
...........
...........
S.........G
EEEE...XXXX
---.....---
```
行の作り方: `'----' + '#'×(g+2) + '--'`、`'....' + '.'×(g+2) + '..'` を 2 行、`'S...' + '.'×(g+2) + '.G'`、`'EEEE' + '.'×g + 'XXXX'`、`'---.' + '.'×g + '.---'`。hop と同じく隙間の下の行も空けておく。

## 7. 1 ステージの組み立て

- **骨組みは Hard と同じ**。足場を左右へつなぎ、壁に当たったら折り返す。普通のジャンプの段差・隙間・足場の長さは Hard の値を使う。
- **区間の並び**を最初に決める。難配置 3〜5 個、癒し区間 1〜2 個を、次の規則で並べる。
  - 難配置は 2 つまでしか続けない。癒し区間は続けない。
  - 最後（ゴールの直前）は難配置にする。
  - 同じ種類を続けない。
- **区間と区間の間**は普通の足場でつなぐ。区間の入口へは必ず普通のジャンプ 1 回で入り、その前に普通の足場を 0〜1 個はさむ（判断）。
- **ネズミ返し**は折り返しのときだけ使い、出る割合は 3 ステージに 1 回程度。次に置く難配置がその向きに置けなかったとき、代わりにネズミ返しを試す。置けたら、その難配置 1 か所として数える。1 ステージに 1 回まで。
- **折り返した直後**は、上へ向かう普通の足場を 1〜2 個置いてから区間を置く（前の列と重ならないように上へずらすため。判断）。
- 並びの途中で置けなくなったら、そこで打ち切る。最後に置いた難配置まで戻し、難配置 3 個以上・癒し区間 1 個以上が残っていれば採用する。足りなければ作り直す。ゴールは最後の区間（難配置）の出口の足場に置く。
- 区間の型が使うマス（`-` 以外）は keep にする。寄り道の足場・柱・菱型は区間の中に入らない。
- 寄り道の足場・柱・菱型は、Hard より少なめから始め、生成の通過率を見て調整する（判断）。

## 8. 検証

1 回の探索で次の 2 つを確かめる（`solveCuts`）。

1. クリアできる（今の `solve` と同じ物理・同じ状態のまとめ方）。
2. どの難配置も飛ばせない。状態ごとに「これまでに本体に触れた難配置」のビット列を持たせて全状態を探索する。ある難配置のビットが立たないままゴールに届いたら、その難配置には抜け道がある。

どちらかを満たさない候補は捨てて作り直す。全状態を探索するので 1 候補あたり 1.5〜3 秒かかる（Node での実測）。

## 11. 方式の比較

- **A. 区間の型＋ステージ全体の検証（採用）**: 実測で段階を確かめた型を経路に組み込み、ステージ全体でクリアできることと飛ばせないことを確かめる。幅は型ごとにあらかじめ測ってあるので、実行時に測る必要がない。見た目で何を要求されているかが分かる。型の種類が限られる点は、変形（g など）と左右反転で補う。
- B. 意図した軌道に沿って菱型を寄せる: 形の自由度は高いが、段階（難配置 / 癒し区間）を狙って作れない。また、幅を実行時に測る必要がある（2 回押す区間では 1 つの測定に数分かかった）ため、生成に使えない。
- C. 菱型を多めにばらまいて探索で選ぶ: 実装は小さいが、アンチゴールの「理不尽な配置」になりやすく、合う候補がほとんど出ない。

## 13. リスク

- **場所が足りない**: 型は 1 つ 7〜12 列あり、25×22 に 4〜7 個と間の足場を詰めると窮屈になる。通過率が低ければ 10 章に従う。
- **到達判定の丸め**: `solve` は位置を 4px 単位でまとめるため、幅 3 の区間を「解けない」と判定することがある。単独の型ではどれも解けた。ステージ全体でこの判定による取りこぼしが増えると、通過率が下がる。
- **飾りによる幅の変化**: 区間のすぐ外の菱型で、区間が測った値より難しくなりうる。本体の周り 8 マスを型の中に収める規則で防ぎ、テストで確かめる。それより外の飾りの影響は測っていない。

## 14. 実装時の変更（2026-11-26）

- **区間の間のつなぎ方**: 7 章の「区間の前に普通の足場 0〜1 個、折り返した直後は上へ向かう足場 1〜2 個」では、1 つ目の区間の先に進めず、80 回中 0 回しか組み上がらなかった。区間の型の中は keep なので、1 回の普通のジャンプでは越えられない。また、上へ向かう足場は、直前のジャンプの上空（keep）に阻まれた。
  そこで、Hard と同じように普通の足場をつなぎ（壁では折り返す）、足場を置くたびに区間を前後どちら向きにも試す方式にした。区間の前の足場は 0〜4 個で、つなぎ方は 30 通りまで試す。始まりの足場は下の方（18〜20 行目）に置く。
- **型の追加の予約**: レビューで、飾りの菱型が型の外を通る軌道に入りうるとわかった。
  - hop: 隙間のマスも本体（`o`）にし、その下に空けておく行を 1 行足した。
  - roomy: 隙間の下に、空けておく行を 1 行足した。
  - overhang: 一番上に、空けておく行 `-.....--` を足した。
  - 幅は変わらない。型のすぐ外のどのマスに菱型が 1 つ来ても、幅の下限と出口までの押下回数が変わらないことをテストで確かめている。
- **MODES.extreme の値**: ネズミ返しを狙う割合 0.25、寄り道の足場 0〜2 個、柱 0〜1 本。寄り道の足場と柱は、区間の抜け道になりやすいため減らした。
- **わかった制約**: 25×22 の盤面では、組み上がるステージは毎回「難配置 3・癒し区間 1」で、並びは H R H H か H H R H の 2 通りになる（2 章の上限側には届かない）。
  試算では、盤面を 25×30 にすると組み上がる割合が約 30% になり、難配置 4 個が 1 割ほど出る。
